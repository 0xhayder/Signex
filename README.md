# Signex

A trustless P2P marketplace for crypto assets and NFTs.

[![Signex](./public/preview.png)](https://app.signex.site)

## Overview

Signex is a Web3 marketplace designed for peer-to-peer trading of crypto assets and NFTs.

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Wagmi
* Viem
* Supabase
